# Demo 影片錄製指引

目標：錄一支 **30~60 秒**的 demo 影片，讓網路上的人 3 秒內看懂 KTV Studio 能做什麼。

## 工具

- **macOS**：內建 QuickTime Player →「檔案」→「新增螢幕錄製」（可同時錄麥克風，記得按 Option 選「內建麥克風」）
- 或 **OBS Studio**（免費，可後製字幕）
- 後製剪接：iMovie / 剪映（把等待的片段剪掉）

## 建議分鏡（照這個順序錄）

| 時間 | 畫面 | 旁白（可省） |
|---|---|---|
| 0–5 秒 | 匯入頁：貼上 YouTube 網址、按「開始處理連結」 | 貼上連結，自動處理 |
| 5–12 秒 | 處理進度頁（**建議剪接加速**，只留 2~3 秒） | 自動去人聲、自動做字幕 |
| 12–30 秒 | 錄唱室：按播放，**鏡頭特寫右邊大字歌詞逐字高亮**（日文歌順便拍羅馬拼音） | 卡拉 OK 逐字字幕 |
| 30–38 秒 | 調音台：拖幾下 EQ 滑桿、點「去刺耳」預設 | 簡易調音 |
| 38–50 秒 | Cover 錄影面板：開鏡頭 → **拖曳字幕位置** → 切字型 → 開始錄影 | 錄 cover 影片 |
| 50–60 秒 | 停止錄影 → 出現「下載 Cover 影片」→ 點開 cover.mp4 播放一下 | 成品直接下載 |

## 錄製重點提醒

1. **字幕一定要「動」**：demo 裡要看到逐字變色，這是最大賣點
2. **用日文歌**：羅馬拼音功能是特色，一眼看出差異
3. **鏡像畫面**：鏡頭開起來就是照鏡子的樣子，這是正常現象
4. **demo 裡的音樂**：建議用你自己的翻唱片段、或 CC 授權音樂，避免版權爭議
5. 品質：螢幕錄製選「Retina」解析度，畫面會比較清楚
